# Q2.0.3 — `reconcile-ticket-status.sh` Format-Option + Human-vs-Auto-Curation-Doc

## Kontext

In Sprint-4 Diagnostic-Passes (mehrere Turns) wiederholte Beobachtung:

- `scripts/reconcile-ticket-status.sh` L80-93 schreibt ein strukturiertes
  Markdown-Bucket-Table (`## 📊 Bucket Distribution`) plus per-Bucket-Detail-Blocks.
- `docs/tickets/STATUS.md` (committed head) zeigt **Listen-Format** mit
  Hand-Curation pro Ticket (deutsche Implementation-Descriptions etc.).

**Diskrepanz:** Das Script wird aktuell nicht regelmäßig ausgeführt (oder die
Auto-Output wird verworfen), während die Hand-Curation mit den Heute-closed-Audit-
Notes wächst.

## Ziel

1. **Klare Optik:** Script dokumentiert explizit, dass es Auto-Reconciliation
   macht und manuell-edited Inhalte überstimmt.
2. **Tooling-Verbesserung:** `--format=table-only|both|list-only` Flag +
   `--dry-run` für sicheres Pre-View.
3. **Format-Frage klären:** Audit-Notes-Sektion bleibt als separater
   Appendix, während Bucket-Table die Auto-Reconciliation-Komponente ist.

## Akzeptanzkriterien

- [ ] **Argument-Parser:** `--format=<table-only|both|list-only>` +
      `--dry-run` + `--help` Flag (Standard: both wie aktuell).
- [ ] **Header-JSDoc explizit erweitert:**
      `bash
    #!/usr/bin/env bash
    # scripts/reconcile-ticket-status.sh
    # ─────────────────────────────────────────────────────────────────────────
    # Auto-reconciles docs/tickets/STATUS.md from per-ticket file-state.
    # OVERWRITES the file on every run. Manual edits are LOST.
    # Manual audit-notes should live in separate files (e.g., a Sprint-Handoff-Log)
    # or as Section unterhalb der Bucket-Section in diesem Script-Lauf.
    # ─────────────────────────────────────────────────────────────────────────
    `
- [ ] **`--dry-run` Mode** printet resolved content to stdout ohne
      File-Write. Hilft beim Pre-Run-Verifizieren.
- [ ] **Help-Output documented** in `scripts/reconcile-ticket-status.sh --help`:
      `     Usage: scripts/reconcile-ticket-status.sh [options]
    Options:
      --format=table-only  Print only the bucket table (no per-bucket detail)
      --format=both        Print bucket table + per-bucket detail (default)
      --format=list-only   Print only per-bucket detail
      --dry-run            Print resolved content to stdout, do not write
      --help, -h           Show this help
    Examples:
      scripts/reconcile-ticket-status.sh --dry-run
      scripts/reconcile-ticket-status.sh --format=table-only | tee STATUS-table.md
    `
- [ ] **Audit-Notes-Section** (Manual-Heute-Closed-Block) wird **separat**
      behandelt: Script könnte optional `--append-audit-notes <path>` Flag
      akzeptieren, der nach den Bucket-Tabellen-Sectionen einen
      Heute-closed-Appendix aus <path> appended.

## Out-of-Scope

- Migration der manuellen Inhalte in ein anderes Format (Audit-Notes bleiben
  Hand-Curation in `STATUS.md` oder separater File).
- Web-UI für Bucket-Status (Dashboard-Tab in `/admin`).
- Cron-Auto-Run (kein Use-Case ohne manuelle Inspection-Bedürfnis).

## Migration-Sketch

```bash
# scripts/reconcile-ticket-status.sh L9-25 — erweiterter Header + Flag-Parser
#!/usr/bin/env bash

FORMAT="both"
DRY_RUN=0
APPEND_AUDIT=""

for arg in "$@"; do
  case "$arg" in
    --format=table-only)     FORMAT="table-only" ;;
    --format=both)           FORMAT="both" ;;
    --format=list-only)      FORMAT="list-only" ;;
    --append-audit-notes=*)  APPEND_AUDIT="${arg#*=}" ;;
    --dry-run)               DRY_RUN=1 ;;
    -h|--help)
      sed -n '2,30p' "$0"
      exit 0
      ;;
    *)
      echo "❌ Unknown flag: $arg"; exit 1 ;;
  esac
done

# L100+ — Format-aware emit
if [ "$FORMAT" = "list-only" ]; then
  # Skip bucket-table emit
else
  printf '## \xf0\x9f\x93\x8a Bucket Distribution\n\n' ...
fi

# Audit-Notes-Append (optional)
if [ -n "$APPEND_AUDIT" ] && [ -f "$APPEND_AUDIT" ]; then
  printf '\n---\n\n## \xf0\x9f\x93\x9d Audit-Notes (geladen aus `%s`)\n\n' "$APPEND_AUDIT"
  cat "$APPEND_AUDIT"
fi
```
