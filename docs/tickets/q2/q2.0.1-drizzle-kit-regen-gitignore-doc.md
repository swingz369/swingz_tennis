# Q2.0.1 — Drizzle-Schema Gitignore-Konvention dokumentieren + Helper-Skript

## Kontext

Diagnose 2026-06-27 (`tsc --noEmit` zeigte TS2307 `Cannot find module '@/drizzle/schema'`)
ergab: `drizzle/schema.ts` (~241 KB) und `drizzle/relations.ts` (~40 KB) sind
**auto-generierte Build-Artefakte** von `drizzle-kit generate` und in
`.gitignore` L23-24 ausgeschlossen. Die **Source-of-Truth** ist
`src/infrastructure/persistence/schema.ts` (2973 Zeilen).

Sprint-4 hat dies in CONTRIBUTING.md Rule 2 dokumentiert. Forward-Ticket
formalisiert die Konvention als Q2.0.1-Ticket für Ticket-Tracking-Parität + plant
optional einen Helper.

## Ziel

1. **Audit-Discipline:** STATUS.md-`Heute audit-driven close`-Note soll die
   `drizzle/`-Konvention explizit als gelernte Lessons referenzieren (aktuell
   nur in CONTRIBUTING.md dokumentiert).
2. **Helper-Skript (optional):** `scripts/regen-drizzle-schema.sh` als
   Docker-fallback-freier Pfad für lokale Regenerierung, falls `drizzle-kit`
   Docker-Pull blockiert ist (siehe Sprint-4-Erfahrung: `postgres-meta:v0.96.1`
   Image war im Sandbox nicht gecacht).

## Akzeptanzkriterien

- [x] **CONTRIBUTING.md Rule 2** dokumentiert die `.gitignore`-Konvention
      (L23-24) und Pfad-zu-Source-of-Truth (`src/infrastructure/persistence/schema.ts`).
- [ ] **STATUS.md-Audit-Notes** verweisen auf die Konvention (Cross-Link
      `[CONTRIBUTING.md](../CONTRIBUTING.md)` Rule 2).
- [ ] **Optional:** `scripts/regen-drizzle-schema.sh` Helper-Skript:
      `bash
    #!/usr/bin/env bash
    # zinc.rs / drizzle-kit pull fallback — wenn Docker-pull blockiert ist
    set -euo pipefail
    # Versuche zuerst drizzle-kit (Docker-basiert)
    if command -v docker >/dev/null 2>&1; then
      npx drizzle-kit pull || {
        echo "⚠️  Docker-pull fehlgeschlagen, fallback auf direkte Schema-Introspection"
        # Fallback: nutze $DATABASE_URL direkt
        npx drizzle-kit pull --driver pg
      }
    else
      npx drizzle-kit pull --driver pg
    fi
    `
- [ ] **README-Update:** `docs/README.md` Quickstart-Section zeigt den neuen
      Helper-Pfad als Alternative zu `npm run db:generate`.

## Out-of-Scope

- Code-Änderungen an `drizzle/schema.ts` (Build-Artefakt, wird regeneriert).
- Migration von bestehender `drizzle/`-Generation auf einen anderen Tool-Stack.
- CI/**workflow**-Änderungen die automatisch `drizzle-kit generate` triggern
  (wäre eine eigenständige Infra-Initiative).
